# Melotrip

Melotrip is an interactive travel-sound archive and melody creation experience.

## GitHub Pages

1. Upload the **contents of this folder** to the root of your GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The opening experience is provided by `index.html`. All pages and assets use relative paths and can be hosted as a static website.

Expected project URL for a repository named `Melotrip`:

`https://lydia-cc88.github.io/Melotrip/`
